# G308 电控组 2026 夏季考核

## 项目说明

本仓库用于记录 G308 电控组 2026 夏季考核的软件与硬件部分的完整开发过程。

## Software

- Q1 Environment：现代 STM32 开发环境配置
- Q2 Servo VOFA：VOFA+ 串口调试舵机
- Q3 CAN：CAN 通信
- Q4 Motor PID：编码器电机、PID、FreeRTOS
- Q5 Gimbal：二自由度舵机云台

## Hardware

- Q1 Minimum System：STM32F103C8T6 最小系统板
- Q2 Buck 24V-5V：24V 转 5V 降压模块
